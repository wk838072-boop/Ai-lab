## Purpose

This lab introduces two approaches for checking scholarship applications: symbolic rules and a threshold-based approach. It also includes a rule-based checker that evaluates applications using specified conditions.

## Project Files

- **`lab1_compare.py`** — Compares scholarship applications using symbolic rules and a threshold-based approach. This code is provided in Section 1.5 of the lab manual.
- **`lab1_rules.py`** — Implements the Task 2 rule-based checker, including two additional conditions and four test cases.
- **`output.txt`** — Contains the captured output of both programs.
- **`Lab1_Report.docx`** — Contains the full lab report, including the timeline, tests, comparison, and reflection.

## Setup Requirements

- Python 3.8 or newer.
- No additional Python libraries are required.

## How to Run

Open a terminal or Command Prompt in the project folder and run:

```bash
python lab1_compare.py
python lab1_rules.py
```

The first command runs the scholarship comparison program. The second runs the rule-based checker.

## Scholarship Thresholds

The lab uses the following example thresholds:

- **Score >= 70** — The score must be 70 or higher.
- **GPA >= 2.5** — The GPA must be 2.5 or higher.
- **Probability >= 0.70** — The probability must be 0.70 or higher.
